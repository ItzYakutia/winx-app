# Проверка MVP — 18 ноября 2026

Проверены оба режима: регистрация и вход, профили, поиск, свайпы, списки переписок, совпадения, уведомления, создание команды, приглашение и состав. Браузерный обход основных 9 страниц выполнен на ширинах 320, 390 и 1366 px; онбординг отдельно проверяется на 320 и 390 px.

## Исправлено

- После регистрации пользователь сразу входит в аккаунт и проходит короткую настройку: имя и город → выбор режима → настройка поиска.
- Шаги сохраняются в профиле на сервере. Перезагрузка и повторный вход продолжают незавершённую настройку. Флаг завершения выставляется после успешного сохранения всех данных.
- Для тиммейтов при первом входе выбираются предметы; навыки и роль необязательны. Для знакомств — дата рождения, пол и предпочтения; интересы и описание необязательны.
- По решению о составе MVP фотографии исключены: нет загрузки, отображения снимков и доступного через gateway API загрузки. В карточках, списках и профилях используются инициалы.
- В команде есть «Пригласить», объяснение кода и вход «Вступить по коду». Предмет команды должен быть выбран в профиле получателя.
- Создатель команды может открыть участника и удалить его. Любой участник может выйти сам; при выходе создателя права переходят следующему участнику. Пустая команда удаляется.
- Имя и город теперь редактируются также в академическом профиле.
- При переходе в знакомства с незаполненными обязательными данными отображается приглашение настроить профиль вместо ошибки API на английском.
- Неудачный свайп в знакомствах возвращает ту же карточку и показывает ошибку; успешный выбор продвигает очередь после ответа сервера.
- Взаимная симпатия определяется по возвращённому совпадению, а не по тексту сообщения API.
- Ошибки загрузки чатов, совпадений, уведомлений и профиля показываются с повтором; пустой экран больше не выдаётся за отсутствие данных.
- При неудачном определении города приложение просит ввести его вручную.

## Осталось проверить и доработать

Это список конкретных ограничений, а не утверждение о полной готовности продукта.

- Соединение чата: проверить автоматическое восстановление после обрыва сети и поведение нескольких одновременно открытых вкладок; текущий сервер хранит одно WebSocket-подключение на пользователя.
- Мобильная клавиатура: необходима проверка на физических iOS/Android-устройствах. Проверка размеров в Chromium не воспроизводит поведение реальной клавиатуры полностью.
- Длинные списки: в знакомствах, совпадениях, уведомлениях и списках чатов нужны отдельная проверка пагинации и сценарии с большим количеством записей.
- Заполненный старый профиль без маркера онбординга считается настроенным. Незаполненные аккаунты проходят новую настройку; массового сброса существующих профилей нет.
- При первом переходе из знакомств в тиммейты предметы добавляются через профиль. Повторного онбординга при переключении режима пока нет.

## Проверка

Сборка frontend, тесты сессий и свайпов, тесты состояния онбординга, Go-тесты profile и gateway. Браузерные сценарии проверяют реальную регистрацию, сохранение и продолжение шагов, обработку отказа сервера и отсутствие фотографий; управление командой проверено с двумя временными аккаунтами. Временные аккаунты удаляются после сценариев.
